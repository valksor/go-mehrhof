# Screenshots

Capture and browse screenshots from agent sessions and manual captures.

## Opening

Open a **Screenshots** tab from the tab bar or the mobile "More" menu. Screenshots load automatically when the tab is active.

## Capturing

Click the **camera icon** button in the header to take a new screenshot.

## Filtering

Use the filter buttons in the header to show:

| Filter | Shows                                              |
| ------ | -------------------------------------------------- |
| All    | All screenshots                                    |
| Agent  | Screenshots captured by AI agents during execution |
| User   | Screenshots captured manually                      |

## Gallery

Screenshots display in a responsive grid (2 columns on mobile, 3 on tablet, 4 on desktop). Each thumbnail shows an image preview with a selection indicator.

- **Click** a thumbnail to open a full-size modal view
- **Select** thumbnails for batch operations using the selection checkmark

## Empty State

When no screenshots exist, the panel shows: "Screenshots will appear here when captured."
