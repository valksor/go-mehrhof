# Queue

Manage the task queue for the current project.

## Location

The queue widget appears in the left sidebar of the Project View. It is always visible when viewing an active project.

## Queue List

Queued tasks display in order with:

- **Position** — Numbered badge (1, 2, 3...)
- **Title** — Task title or source identifier
- **Source** — Source URL (shown below the title)

## Adding Tasks

Click the **+** button in the queue header to open the add form:

1. Enter a task source (e.g., `github.com/owner/repo/issues/123`)
2. Optionally add a title
3. Press Enter or click **Add**

Click **Cancel** to close the form without adding.

## Reordering

Hover over a queued task to reveal arrow buttons:

- **Up arrow** — Move the task up one position (disabled if already first)
- **Down arrow** — Move the task down one position (disabled if already last)

## Removing

Hover over a queued task and click the **X** button to remove it from the queue.

## Empty State

When the queue is empty and the add form is closed, the widget shows "No tasks in queue."
