# Catalog

Browse and import task templates for common workflows.

## Opening

Click the template icon in the top-right of the Global View header. The panel opens as a modal overlay.

## Browsing Templates

Templates display as a card grid showing name, description (truncated to 2 lines), and colored tag badges. Click any card to view its full details.

## Template Details

The detail view shows:

- Full name and description
- Source and agent configuration
- Complete tag list

Click **Back** to return to the card grid.

## Importing Templates

Enter a file path in the import field at the top and press Enter or click **Import**. The template file is loaded and added to the catalog. Success or error feedback appears as an alert.

## Empty State

If no templates exist, the panel shows a prompt to import one.
