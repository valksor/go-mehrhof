# Memory

Search and manage the semantic memory store used by agents for context.

## Opening

Click the light bulb icon in the top-right of the Global View header. The panel opens as a modal overlay.

## Stats

Three metrics display at the top:

| Metric        | Description                                 |
| ------------- | ------------------------------------------- |
| Total Entries | Number of stored memory entries             |
| Total Size    | Storage size (formatted as B/KB/MB/GB)      |
| Index Status  | **Ready** (green) or **Not ready** (orange) |

## Searching

Enter a query in the search field and press Enter or click **Search**. Results show as cards with:

- **Type badge** — Color-coded: Task, Specification, Plan, Note, or Snippet
- **Task ID** — First 8 characters (if associated with a task)
- **Relevance score** — Green (>= 0.8), orange (>= 0.5), or gray (lower)
- **Date** — When the entry was created
- **Content preview** — First 4 lines of the stored content

The result count displays above the list (e.g., "12 results found").

## Clearing Memory

Click **Clear Memory** in the top-right corner. A confirmation step appears — click **Confirm Clear** to delete all memory entries. The confirmation cancels if you click elsewhere.
