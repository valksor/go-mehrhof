# Export

Export kvelmo data as JSON for reporting or external analysis.

## Opening

Open the Export panel from the sidebar. It loads as a modal overlay.

## Global Export

Export data across all projects. Configure what to include:

| Option     | Choices                                              |
| ---------- | ---------------------------------------------------- |
| Time range | Last 7 days, 30 days, or 90 days                     |
| Data       | All data, tasks only, metrics only, or activity only |

Click **Download JSON** to save the export file.

## Current Task Export

Export full context for the active task in the current project. The export includes metadata, specification, chat history, diff, and checkpoints.

Click **Download Task JSON** to save. This button is disabled when no task is active.
