# Report

Generate compliance reports across all kvelmo activity.

## Opening

Click the chart icon in the top-right of the Global View header. The panel opens as a modal overlay.

## Generating a Report

Configure the report parameters:

| Option     | Choices                          |
| ---------- | -------------------------------- |
| Time range | Last 7 days, 30 days, or 90 days |
| Format     | Markdown or JSON                 |

Click **Generate** to create the report. The button is disabled when not connected to the server.

## Output

Reports render in a scrollable content area:

- **Markdown** — Rendered as plain text in monospace font, suitable for pasting into documents or tickets
- **JSON** — Pretty-printed structured data, suitable for programmatic analysis

## Empty State

Before generating, the panel prompts you to select a time range and format.
